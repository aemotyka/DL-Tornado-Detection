## TorNet

This repository does not contain or redistribute TorNet data.

TorNet is an external dataset created by MIT Lincoln Laboratory and described in:

> Mark S. Veillette, James M. Kurdzo, Phillip M. Stepanian, John Y. N. Cho, Siddharth Samsi, and Joseph McDonald. *A Benchmark Dataset for Tornado Detection and Prediction using Full-Resolution Polarimetric Weather Radar Data.*

The official TorNet software repository is MIT-licensed. The Zenodo dataset records state that the data are approved for public release, but they do not identify a standard dataset license in the Rights field. Users should download TorNet from its official source and follow the terms supplied by MIT Lincoln Laboratory.

The MIT License in this repository does not apply to TorNet data.
